# 物管日常工作台 使用指南

（富善邨管業處 · 最後更新 2026-10-12）

## 呢個係乜嘢

物管日常工作台係一個網頁程式，幫你記低每日嘅工作，再幫你出信同出表。唔使安裝，手機、電腦都用得。

佢做到嘅嘢：

- 記低投訴個案，提你幾時要覆住戶
- 打個單位號碼，即刻見到住戶係業戶定租戶、有冇長者、電話幾多
- 影張相、打個單位，就出到一封樓層雜物信（Word）
- 樓層巡查一格格剔，再印成剔格表或者雜物表（Excel）
- 跟進工程項目、承辦商同信件編號
- 直接讀公司現有嘅 Excel，唔使重新打

資料存喺邊：全部存喺你自己部手機或者電腦嘅瀏覽器入面，唔會上載去任何地方。所以要記得定期備份（見最後一節）。

邊個用：管業處同事。住戶資料只可以用喺管理工作上。

## 點樣打開

呢一節教你點樣打開個程式。
第一次用嗰陣會用到。

呢個程式係一個網頁。唔使安裝。
網頁即係用上網嘅程式開嘅頁。
有兩個版本，揀一個用就得：

- 網上版：用連結開。連結即係一個網址。要上網，要登入。
- 單一檔案版：一個檔案。冇網絡都開到。

唔知揀邊個？先用網上版。

### 一、用連結開（網上版）

呢節教你用連結開個程式。
有網絡嗰陣就用呢個方法。
做完會點：你會見到「今日」頁。

1. 打開瀏覽器。瀏覽器即係上網用嘅程式。Safari、Chrome 或者 Edge 都得。
2. 睇最頂。有一格打字嘅地方，叫網址欄。
3. 喺網址欄打呢個網址：
   https://claude.ai/artifact/PejQSNXR1opX1SyDXSAKWY
4. 撳 Enter。Enter 係鍵盤上嘅輸入鍵。
5. 見到登入畫面，就登入 claude.ai。登入即係用你個帳戶入去。
6. 冇帳戶？就先開一個帳戶。
7. 等一陣。
8. 睇最頂。見到大字寫住今日日期，就得喇。例如：2026年10月12日。即係開咗「今日」頁。

用電腦開，左邊有一排選單。「今日」係第一項。
用手機開，選單收埋咗。淨係見到左上角「☰」掣。「☰」即係三條橫線。撳一下，選單就彈出嚟。揀咗一頁，選單會自己收返埋。

[[img:today]]

要留意三樣嘢：

- 呢條係私人連結。檔主要先分享畀你。檔主即係呢個程式嘅主人。點樣分享，睇「五、分享畀同事」。
- 第一次開，會見到一句淺藍色提示。寫住「而家顯示嘅係示範資料」。示範資料即係假嘅例子。畀你試玩。真正用之前，要先清走。點清走，睇「第一次用」一節。
- 網上版可以下載檔案。例如 Word、Excel 或者備份檔。下載即係將檔案攞落嚟部機。備份即係留多一份資料。網上版下載會先彈一個框。個框問你儲唔儲存。撳同意，先會下載。落到嚟之後，頁底會閃「已儲存」。

### 二、下載單一檔案版

呢節教你攞單一檔案版。
想冇網絡都用到，就要攞呢個檔案。
個檔案叫 pmo-workbench.html。
做完會點：你部機會多咗呢個檔案。

最簡單：問同事要。

1. 叫有檔案嘅同事傳畀你。電郵或者 WhatsApp 都得。呢個檔案淨係程式。冇住戶資料。所以傳得。
2. 收到之後，撳一下個檔案。
3. 揀儲存。用電腦，會存入下載資料夾。下載資料夾即係放落嚟檔案嘅地方。用手機，會存入「檔案」App。App 即係應用程式。

冇人有檔案？自己去 GitHub 攞。GitHub 係放檔案嘅網站。

1. 用瀏覽器打開呢個網址：
   https://github.com/N4m313555/FUSN/blob/claude/property-officer-software-slthsx/dist/pmo-workbench.html
2. 撳「Download raw file」掣。個掣係一個向下箭咀。意思係下載檔案。
3. 檔案會存入下載資料夾。

如果個網頁叫你登入，或者話搵唔到。
即係呢個網站要有權限先開到。
咁就問同事要檔案。

### 三、喺電腦開

呢節教你喺電腦開單一檔案版。
攞到 pmo-workbench.html 之後就用到。
做完會點：瀏覽器會開住個程式。

1. 搵返 pmo-workbench.html。通常喺下載資料夾。
2. 雙擊佢。雙擊即係快速撳兩下。
3. 瀏覽器會自動開。Chrome、Edge、Safari 或者 Firefox 都得。
4. 如果開咗其他程式：喺檔案上面撳右掣。右掣即係滑鼠右邊個掣。再揀用 Chrome 開。

第一次開係空嘅。「今日」頁會見到「開始使用」提示。
之後去「設定／備份」。做第一次設定。點做，睇「第一次用」一節。

好緊要：以後都用同一部機開。都用同一個瀏覽器開。
因為資料係存喺個瀏覽器入面。
換咗瀏覽器，資料就見唔返。換咗機都係。清咗瀏覽紀錄都係。
所以要定期備份。程式都會提你：每星期匯出一次。
匯出即係將資料存做一個檔案。
點做備份，睇「備份同常見問題」一節。

### 四、放上手機主畫面（當係 App 用）

呢節教你將程式放上手機主畫面。
主畫面即係手機一開就見到嗰頁。
想撳一下就開，好似 App 咁，就睇呢節。
做完會點：主畫面會多一個圖示。圖示即係一個細圖。撳一下就開，同用 App 一樣。

iPhone：

1. 用 Safari 開網上版連結。
2. 撳底部「分享」掣。個掣係一個方格，上面有向上箭咀。
3. 向上掃，搵「加至主畫面」。
4. 撳「加至主畫面」。
5. 撳右上「新增」。

Android：

1. 用 Chrome 開網上版連結。
2. 撳右上「⋮」。即係三個直點。
3. 揀「加到主畫面」或者「安裝應用程式」。
4. 撳「新增」。

要留意：

- 網上版要有網絡。亦要登入咗 claude.ai。
- 手機畫面細，選單會收埋。點開選單，睇「一、用連結開」。
- 想喺手機用單一檔案版？先將檔案存入「檔案」App。再用 Safari 或者 Chrome 開佢。


### 五、分享畀同事

呢節教你畀同事都用到呢個程式。
同事想用嗰陣就睇呢節。

網上版（分享連結）：

做完會點：同事用自己帳戶登入就開到。

1. 檔主開網上版。
2. 撳右上「Share」。Share 即係分享。
3. 跟畫面指示分享畀同事。
4. 將連結傳畀同事。

單一檔案版（傳檔案）：

1. 將 pmo-workbench.html 傳畀同事。電郵或者 WhatsApp 都得。
2. 同事存落自己部機。
3. 同事跟「三、喺電腦開」嘅步驟開。

好緊要：分享嘅只係程式，唔係資料。
每部機嘅資料各自存。
同事開單一檔案版，係空嘅。
同事開網上版，會見到示範資料。要先清走。點清走，睇「第一次用」一節。

想將資料畀同事：

1. 你去「設定／備份」，撳「匯出 JSON」。JSON 係備份檔嘅格式。會落一個檔案，叫 pmo-backup-日期.json。
2. 將備份檔放喺公司指定位置。畀同事自己攞。唔好用 WhatsApp 傳。唔好用私人電郵傳。唔好放個人雲端。雲端即係網上嘅儲存位。
3. 同事去「設定／備份」，撳「匯入 JSON」。匯入即係將檔案入面嘅資料攞入嚟。
4. 同事揀你個備份檔。會彈一個「確認」框。話會覆蓋現有資料。覆蓋即係用新資料換走舊資料。
5. 撳「確定」。頁底會閃「已匯入」。唔想覆蓋，就撳「取消」。

詳細步驟，睇「備份同常見問題」一節。

備份檔有住戶個人資料。
程式入面都有提：要存喺公司指定位置。唔好放個人雲端。唔好傳出去。

## 第一次用

呢節教你第一次開程式要做乜。
第一次開程式嗰陣先會用到。

第一次開程式，要做四件事。
一、清走示範資料。
二、套用富善邨預設。
（預設即係預先準備好嘅一套資料。）
三、填你自己嘅姓名同牌照。
四、將公司嘅 Excel 匯入。
（Excel 即係電腦表格檔案。）

次序好緊要。
「清除全部資料」會連設定一齊清走。
所以一定要先清，後設定。
如果掉轉做，姓名同牌照會冇咗。

### 第一步：清走示範資料

呢節教你點樣清走假嘅示範資料。
網上版第一次開嗰陣會用到。

網上版第一次開，會見到好多假個案。
點樣知係假？
睇「今日」頁頂。
日期下面有一條藍色提示。
寫住「而家顯示嘅係示範資料」。
呢啲全部係假嘅例子。
要先清走，先可以放真資料。

做完會點：個案、承辦商、信件會全部清空。
（承辦商即係做工程嘅公司。）
「今日」頁會變成一句「開始使用」。

1. 撳左邊選單嘅「設定／備份」。
2. 搵「危險區」呢一格。
3. 撳紅色字嘅「清除全部資料」。
4. 會彈一個「確認」框。上面寫住「清除全部資料？先匯出備份。」
5. 撳「確定」。
6. 頁底會閃「已清除」就得。

如果「今日」頁頂冇藍色提示，
即係冇示範資料。
咁就可以跳過呢一步。

### 第二步：套用富善邨預設

呢節教你一次過填好屋邨嘅基本資料。
做完第一步，就做呢步。

做完會點：呢啲嘢會自動填好。
六座名同代號、A翼 B翼 C翼。
同事名單、法團名稱、簽署人。
信件編號前綴、個案編號前綴。
（前綴即係編號最前面嗰幾個字。）
你唔使逐個打。

[[img:settings]]

1. 留喺「設定／備份」頁。
2. 撳「套用富善邨預設」。
3. 會彈一個「確認」框。
4. 個框會寫：現有姓名同牌照號碼唔會被覆蓋。
5. 撳「確定」。
6. 頁底會閃「已套用」就得。

檢查一下有冇填好。
搵「座（每行一個：名稱 代號）」。
入面會有六行。
善景樓 SG、善美樓 SM。
善雅樓 SN、善翠樓 ST。
善群樓 SK、善鄰樓 SL。
（代號即係座名嘅英文簡寫。）
「信件編號前綴」係 FUSN/26/L。
「個案編號前綴」係 FUS26-。

### 第三步：填你自己嘅資料

呢節教你填自己嘅姓名同牌照。
做完第二步，就做呢步。

做完會點：信尾會自動加你個名。
仲會自動加你嘅牌照號碼。
每封信都係咁。

1. 搵「你嘅資料（信件會自動用）」呢一格。
2. 喺「姓名」打你個名。
3. 喺「物業管理人牌照號碼」打你嘅牌照號碼。
4. 睇「電話」。
5. 入面已經填咗管業處電話。
6. 唔啱就改返。
7. 撳「儲存」。
8. 頁底會閃「已儲存」就得。

### 第四步：匯入公司嘅 Excel

呢節教你匯入公司嘅 Excel。
做完第三步，就做呢步。

即係將公司現有嘅表搬入程式。
檔案唔會送去任何地方。
全部喺你部機入面做。

有四份表要匯入。
照呢個次序做：
一、投訴登記表。
二、工程表。
三、住戶登記表。
四、信件紀錄。
先入投訴登記表。
咁工程表先可以自動連結返個案。
（連結即係同個案駁返埋一齊。）

匯入嗰陣會見到下拉選單。
（下拉選單即係撳落去會彈個名單揀。）

#### 匯入投訴登記表

呢節教你匯入投訴登記表。
四份表入面，呢份要最先入。

做完會點：每行投訴會變成一個個案。
有啲行，「已完成個案」嗰欄寫咗「完成」。
呢啲行會自動結案。
（結案即係當佢已經做完。）

1. 撳左邊選單嘅「匯入 Excel」。
2. 撳「揀檔案」下面個掣。
3. 揀公司嘅投訴登記表檔案。
4. 等一陣。
5. 會出現「工作表」同「當作」兩個下拉選單。
6. 睇「當作」。
7. 應該係「投訴登記表 → 個案」。
8. 唔係就撳「當作」，自己揀返。
9. 下面會顯示頭五行畀你睇。
10. 撳「匯入」。
11. 睇到「已匯入」後面有個數字就得。
12. 下面會有一個「完成」框。
13. 撳「去睇」可以即刻睇個案。

#### 匯入工程表

呢節教你匯入工程表。
入完投訴登記表，就入呢份。

做完會點：每項工程會入「工程項目」。
表入面嘅承辦商會自動加入「承辦商」。
有「首宗投訴編號」嘅會自動連結返個案。

一個 Excel 入面可以有好多頁。
程式會自動揀一頁。
佢會揀名有「工程項目」嗰頁。
或者名有「工程進度」嗰頁。
或者名有「處理中」嗰頁。

1. 撳「揀檔案」下面個掣。
2. 揀公司嘅工程表檔案。
3. 睇「工作表」。
4. 程式已經自動揀咗一頁。
5. 唔啱先自己揀返。
6. 睇「當作」。
7. 應該係「工程項目／工程進度／處理中 → 工程項目」。
8. 睇下有冇幾頁同類嘅表。
9. 有就剔「一併匯入同類型嘅其他工作表」。
   （剔即係撳一下，打個剔。）
10. 撳「匯入」。
11. 「完成」框會寫「新增承辦商」幾多間。
12. 都會寫「連結個案」幾多宗。

冇新承辦商、冇連結到個案嘅話，
呢兩句就唔會出現。

#### 匯入住戶登記表（有密碼）

呢節教你匯入有密碼嘅住戶登記表。
入完工程表，就入呢份。

住戶登記表有密碼鎖住。
程式會問你密碼。
解密喺你部機入面做。
（解密即係用密碼開鎖。）
密碼唔會傳出去。

做完會點：「單位查詢」就查到嘢。
每戶嘅住戶同電話都查到。

1. 撳「揀檔案」下面個掣。
2. 揀住戶登記表檔案。
3. 會彈「呢個 Excel 有密碼」。
4. 喺「密碼」打密碼。
5. 撳「解密」。
6. 等幾秒。
7. 會見到「解密中…」，後面有個百分比。
   （百分比即係做咗幾多。）
8. 見到「已解密」就得。
9. 睇「當作」。
10. 應該係「住戶登記表 → 住戶」。
11. 睇下有冇「一併匯入同類型嘅其他工作表」。
12. 檔案有幾頁同類嘅表，先會有呢句。
13. 有嘅話，佢已經自動剔咗。
14. 咁六座會一次過入晒。
15. 撳「匯入」。

密碼打錯，會話「密碼唔啱，再試」。
個框會再彈出嚟。
再打一次就得。
唔想繼續，撳「取消」。
仲係唔得，問返畀你檔案嗰位同事。

#### 匯入信件紀錄

呢節教你匯入舊信嘅紀錄。
入完住戶登記表，就入呢份。

做完會點：舊信全部入「信件紀錄」。
下一個信件編號會自動接住舊嘅。
（接住即係跟住舊編號繼續數。）

1. 撳「揀檔案」下面個掣。
2. 揀公司嘅信件紀錄檔案。
3. 睇「當作」。
4. 應該係「屋苑信件紀錄 → 信件紀錄」。
5. 撳「匯入」。

### 唔小心匯入咗兩次點算

呢節講同一份表入咗兩次會點。
入錯咗兩次嗰陣先會用到。

唔怕。
已有嘅編號或者單位唔會加多次。
「完成」框會寫跳過咗幾多筆。

做完呢四步，就可以開始用。

## 每日點用

呢節教你每日返工點用個程式。
由開程式、查單位、到跟個案，一步步教。

### 今日頁：一開就睇

呢節教你睇「今日」頁。
每日一開程式就會用到。

一打開程式，就係「今日」頁。
想返去呢頁，撳左邊選單「今日」。

用手機想返去「今日」頁：

1. 撳左上角「☰」掣。
2. 撳「今日」。


頁頂係今日嘅日期。
日期下面有四個大數字格：

- 「逾期跟進」：過咗期限仲未做嘅個案。
- 「應承咗覆嘅（到期）」：應承咗覆人嘅。
  今日到期，或者已經過咗期。
- 「今日要做」：下一步期限係今日。
- 「兩個月冇進展」：六十日冇實質進展。
  實質進展即係真係有嘢做到。
  安全個案唔計入呢格。

撳一個格，畫面會跳去嗰一欄。

再落去係一欄欄嘅名單。
次序係咁：

1. 「應承咗覆命」：要覆投訴人嘅個案。
2. 「逾期跟進」：過咗期限嘅個案。
3. 「今日到期」：今日要做嘅個案。
4. 「承辦商工單超時」：承辦商過咗限期。
   工單即係派畀承辦商做嘅工作。
   超時即係過咗限期仲未做完。
5. 「工程項目」：呢啲工程會出現喺度：
   - 截標到咗，但未定承辦商。
   - 約期／工程中，超過三十日未完工。
   - 等上會追認嗰啲。
   截標即係收標書嘅最後一日。
   追認即係事後先攞上會批。
6. 「樓層雜物」：呢啲雜物會出現喺度：
   - 阻住走火通道，仲未清。
   - 第一次信出咗七日，仲未清。
   - 發現咗三日，仲未出信。
   走火通道即係火燭時走嘅路。
7. 「樓層巡查」：邊座超過七日未巡。
8. 「連續兩個月冇實質進展——要決定升級定結案」。
   呢欄嘅個案，要決定升級定結案。
9. 「未來七日」：未來七日到期嘅個案。

有五欄一定會出現。
冇嘢就會寫「冇」。
呢五欄係：

- 「應承咗覆命」
- 「逾期跟進」
- 「今日到期」
- 「連續兩個月冇實質進展——要決定升級定結案」
- 「未來七日」

有四欄冇嘢就成欄唔會出現。
呢四欄係：

- 「承辦商工單超時」
- 「工程項目」
- 「樓層雜物」
- 「樓層巡查」

有安全個案，頁頂會有個紅色框。
框入面寫住「安全個案」同幾多宗。
仲寫住「即時處理，唔入酌情計算」。
唔入酌情計算，即係唔使計值唔值得。
安全即係走火通道、消防、結構。
呢三種情況都算安全個案：

- 個案類型揀咗「走火通道／消防設備阻塞」。
- 個案類型揀咗「結構危險／石屎剝落」。
- 開個案時剔咗安全嗰格。

安全個案要即刻處理。

名單每一行就係一宗個案。
撳一行，就入到嗰宗個案。
有幾欄撳咗會去另一頁：

- 「承辦商工單超時」：去承辦商頁。
- 「工程項目」：去工程頁。
- 「樓層雜物」：去樓層雜物嗰頁。
- 「樓層巡查」：去樓層巡查嗰頁。

每日咁做：

1. 由上望落。紅色框最先處理。
2. 撳一行，入個案。
3. 做完嘢，撳「記一筆」記低。下面會教。
4. 撳左邊選單「今日」返嚟。
5. 睇下一行。

見到藍色框寫住「而家顯示嘅係示範資料」。
即係而家啲資料係假嘅。
真正用之前，要清走。
點清走，睇「第一次用」一節。

### 單位查詢：一打就見晒

呢節教你查一個單位嘅資料。
有住戶打嚟講嘢，想即刻睇佢單位，就用呢度。

先記住六座嘅代號。
六座代號，睇「第一次用」第二步。
呢啲代號唔係一開始就有。
要先去「設定／備份」。
撳過「套用富善邨預設」先會有。

方法一：用頁頂搜尋框。
搜尋框即係畀你打字搵嘢嘅格。

1. 撳頁頂嘅搜尋框。
   框入面有灰字，寫住：
   「單位查詢：SK707 / 善群樓 707」
2. 打單位代號，例如 SK707。
   或者打中文，例如 善群樓 707。
3. 撳鍵盤嘅 Enter 鍵。
   用手機，就撳鍵盤右下角嗰粒確定掣。
4. 搜尋框會自動清空。
   畫面會跳去單位查詢頁。

方法二：用左邊選單。

1. 撳左邊選單「單位查詢」。
2. 「座」揀一座。
3. 「單位（或者直接打 SK707）」打號碼。
   例如 707。
   呢格可以直接打代號，例如 SK707。
   打咗代號，就用代號嗰座。
   「座」揀咗咩都唔理。
4. 撳「查」。

做完會點：即刻見到呢個單位嘅資料。

- 頂部：座、樓層、翼、單位代號。
- 三個掣：「新個案」「出雜物信」「新工程」。
  撳「出雜物信」，會去「樓層雜物」頁。
  單位要自己再打一次。
- 「住戶」一格：
  - 係業戶定租戶。
    業戶即係買咗層樓嘅人。
    租戶即係租緊嘅人。
  - 65歲以上、退休、獨居嘅標記。
  - 「身份」同「關顧」。
  - 「住戶及聯絡」：姓名同電話。
  - 用手機，撳電話號碼可以直接打。
  - 「緊急聯絡人」。
  - 備註。
  - 住戶表入面冇呢個單位。
    咁會寫「住戶登記表冇呢個單位」。
- 「相關紀錄」一格。
  標題後面有個括號，寫住有幾多項。
  - 呢個單位所有個案、工程、雜物、信件。
  - 按日期排，最新喺最上。
  - 撳一行可以入去睇。
    雜物會去「樓層雜物」頁。
    信件會去「信件紀錄」頁。

要留意：

- 喺頁頂搜尋框淨係打 707，冇打座代號。
  咁會見到提示：
  「請揀座，或者用座代號打，例如 SK707。」
- 見到「未匯入住戶登記表」。
  即係未入住戶資料。
  個案、工程、雜物照查到。
- 住戶資料只可以用嚟做管理。
  唔好傳出去。

喺個案頁都有捷徑去單位查詢。
捷徑即係一撳就去到嘅快路。
「基本資料」入面有「位置」。
「位置」旁邊有「單位紀錄」。
「住戶登記」嗰行旁邊有「詳細」。
撳一下就去到單位查詢。

### 個案跟進

呢節教你開個案、記接觸、覆人、結案。
由收到投訴，到搞掂為止，都用呢度。

[[img:case]]

#### 開新個案

呢節教你開一宗新個案。
收到投訴，第一步就係開個案。

有三個地方可以開：

- 頁頂右邊「新個案」掣。
- 左邊選單「個案」，再撳「新個案」。
- 單位查詢頁撳「新個案」。
  座、單位、處所類型會自動填好。
  投訴人姓名同電話都會自動填好。
  住戶係長者或者獨居，會自動剔咗呢格：
  「涉及弱勢住戶——要轉介支援」

做完會點：自動跳去個案頁。
會見到「已儲存」。
個案會自動有編號。

1. 撳「新個案」。
2. 「標題」打一句講咩事。
   例：善群樓 707 天花滲水。
3. 「類型」揀最似嘅一個。
   例：「滲水」「噪音」「走廊／大堂雜物」。
4. 「處所類型（決定晒之後所有嘢）」：
   揀呢個單位係咩類。
   房委會租住，揀「房委會租住單位」。
   已經買咗，揀「租者置其屋計劃單位」。
   由單位查詢開嘅新個案，呢格會自動揀好。
   住戶表寫租戶，就揀「房委會租住單位」。
   其他就揀「租者置其屋計劃單位」。
   要睇清楚啱唔啱。
5. 「座」打座名。
6. 「樓層／單位／位置」打單位號或者位置。
7. 「開立日期」已經係今日。唔使改。
8. 「投訴人」打名。
9. 「投訴人聯絡」打電話。
10. 「被投訴方／對方」打名。冇就留空。
11. 「對方聯絡」打電話。冇就留空。
12. 「相關承辦商」同「狀態」，新個案唔使郁。
    「狀態」預設係「跟進中」。
13. 「下一步」打邊個做咩。
    例：約星期四上門。
14. 「下一步期限」揀日子。
15. 「應承咗幾時覆投訴人」揀應承咗嘅日子。
16. 「涉及安全（走火通道、消防、結構）——即時處理」：
    關走火通道、消防、結構嘅，就剔。
    剔咗，「今日」頁會紅色置頂。
    置頂即係擺喺最上面。
17. 「涉及弱勢住戶——要轉介支援」：
    住戶係長者或者獨居，就剔。
    弱勢住戶即係要多啲照顧嘅人。
18. 「備註」打其他要記嘅嘢。
19. 撳「儲存」。
    唔想開呢宗，就撳「取消」。

個案頁頂部有呢啲掣：

- 「編輯」：改資料。
- 「出信」：去寫信。
- 「準備對話」：預備點同人講。
- 「判斷」：睇值唔值得推落去。
- 「結案」：完成個案。
- 「刪除」：成宗刪走。
  刪咗就冇得攞返。
  會先彈個框問你。
  撳「確定」先會刪。

「手段階梯」一格有四級：

- 「非正式溝通」
- 「借助第三方」
- 「正式程序」
- 「法律／租約行動」

階梯即係一級一級咁上。
第三方即係你同對方以外嘅人。
下面有「升一級 →」。
用嚟由傾，升級去搵第三方、出信、正式程序。

升級咁做：

1. 撳「升一級 →」。會彈個框。
2. 「點解升級（寫入紀錄）」打原因。
3. 撳「確定升級」。

升咗級，會自動記一筆落接觸紀錄。
升錯咗，撳「← 降一級」。
上一層未試過，唔好跳級。
跳級即係跳過中間嗰級。

#### 記一筆：每次接觸都要記

呢節教你記低每一次接觸。
接觸即係上門、打電話、見面。
每次做完，即刻記。

做完會點：「接觸紀錄」會多咗一行。
最新嗰行喺最上面。
個案嘅下一步同期限會一齊更新。
應承覆嘅日子都會更新。

1. 撳「今日」或者「個案」頁嘅一行，入個案。
2. 落去「接觸紀錄」一格。
3. 撳「記一筆」。
   會彈出「記一筆接觸」嘅框。
4. 「日期時間」已經自動填好。唔啱就改。
5. 「渠道」揀一個。
   渠道即係用咩方法接觸。
   有呢幾個：
   「上門」「電話」「櫃檯」「書面」
   「WhatsApp／短訊」「會議」「巡查」
6. 「對方係邊個」已經自動填好。唔啱就改。
7. 「對方原話（記事實，唔記情緒）」：
   打對方講咗咩。
   只寫事實。
   例：對方表示不滿並要求即時處理。
   唔好寫：對方好嬲。
8. 「結果」打今次搞成點。
   例：有應門但冇入到。
9. 「下一步」打跟住做咩。
   呢格已經填住上次嘅下一步。
   唔啱就改。
10. 「下一步期限」揀日子。
11. 「應承幾時覆投訴人」揀日子。
12. 今次係上門，「渠道」要揀「上門」。
13. 再剔「呢次係上門嘗試（計入次數）」。
    兩樣都做咗，上門次數先會加一。
    唔係上門，呢兩步唔使做。
    滲水個案，呢格預設已經剔咗。
14. 「算係實質進展」預設已經剔咗。
    真係有進展，就留住個剔。
    淨係傾咗、冇結論，就除咗個剔。
15. 撳「儲存」。

儲存後會提你：
「已記錄。記得即日出紀錄信。」
口頭傾完，當日就撳「出信」出紀錄信。

#### 應承覆命：應承咗就一定要覆

呢節教你應承咗覆人之後點做。
到咗應承嘅日子，就會用到。

「應承咗幾時覆投訴人」填咗日子。
程式會幫你記住呢個日子。
到咗嗰日，「今日」頁會提你。
「應承咗覆命」嗰欄會有呢宗個案。
數字格「應承咗覆嘅（到期）」會加一。
個案頁頂會有黃色提示。
寫住應承咗邊日前覆投訴人。
就算未有結果，都要覆。

覆完要咁做：

1. 喺「今日」頁「應承咗覆命」撳嗰宗個案。
2. 打電話或者見面，覆投訴人。
3. 撳「記一筆」。
4. 「渠道」揀「電話」，或者實際用嘅方法。
5. 「結果」打已覆投訴人，同講咗咩。
6. 「應承幾時覆投訴人」呢格：
   再應承咗，就揀新日子。
   冇再應承，就清空個日子。
   唔清空，「今日」頁會繼續提你。
7. 撳「儲存」。

做完，「今日」頁嗰欄就唔會再有呢宗。
淨係想改日子，就咁做：
撳「編輯」，改「應承咗幾時覆投訴人」。

#### 結案

呢節教你結案。
結案即係呢宗個案完結咗。

幾時結案：

- 修好咗。
- 投訴人確認冇事。
- 決定唔再推。

結案唔等於唔記錄。
一定要寫低原因。

1. 入個案。
2. 撳頂部「結案」。
   會彈個框，寫住結案同個案編號。
3. 「結案原因」打點解結案。一定要填。
   例：已修復。
   例：投訴人確認冇再滲。
   例：決定唔再推，對方唔郁，三個月後再睇。
4. 撳「結案」。
   唔結住，就撳「取消」。

做完，「狀態」會變「已結案」。
旁邊有結案日期同原因。
「今日」頁唔會再提呢宗。
下一步期限同應承日期會自動清空。

想搵返已結案嘅個案：

1. 撳左邊選單「個案」。
2. 最右邊有個下拉選單。
   佢預設係「未結案」。
3. 揀「全部」或者「已結案」。

結錯咗，可以重開：

1. 入個案。
2. 頂部嗰個「結案」掣，會變咗「重開」。
3. 撳「重開」。

「刪除」同「結案」唔同。
「刪除」會成宗冇咗。
刪咗就冇得攞返。

## 樓層雜物

呢節教你點樣處理走廊雜物。走廊有雜物，就用呢一頁。做法好簡單：影張相，打個單位，信就出到。

### 打開樓層雜物頁

呢節教你點樣入去雜物頁。每次要處理雜物，都由呢度開始。

1. 撳左邊選單「樓層雜物」。
2. 頁頂有一行掣，一共五個：
   - 「樓層巡查」
   - 「列印雜物表」
   - 「下載雜物表 Excel」
   - 「匯出 CSV」
   - 「新增（唔出信）」

   CSV 係另一種簡單表格檔案。可以用 Excel 開。

3. 跟住係「快速出雜物信」一格。
4. 再下面係雜物表。
5. 表入面一行，就係一筆雜物紀錄。


### 快速出雜物信（影相＋單位→Word）

呢節教你最快點樣出一封雜物信。見到雜物，想即刻出信，就用呢個格。

做完會點：程式會自動下載一封 Word 信。Word 即係電腦打信用嘅檔案。同時會記入雜物表。亦會記入「信件紀錄」。

[[img:debris-quick]]

1. 喺「座」揀邊一座。
2. 喺「單位（例 707、2118）」打單位號碼。
3. 下面淺藍色一行會即刻顯示資料。
4. 會顯示樓層、翼、第幾次通知、信件編號、日期。
5. 睇一睇啱唔啱。
6. 喺「物品（信入面寫「擺放……」）」打有咩嘢。
7. 呢格預設寫住「雜物」。
8. 可以改做例如：紙箱三個。
9. 「位置」預設係「樓層走廊」。
10. 唔啱就改。可以揀：
    - 「後樓梯」
    - 「大堂」
    - 「電梯大堂」
11. 或者自己打。
12. 喺「跟進同事」揀邊個跟。
13. 撳「相片（可以多張，手機可直接影）」。
14. 手機會開相機，即場影。
15. 或者畀你揀相簿入面嘅相。
16. 唔同手機，畫面可能唔同。
17. 可以揀多張。
18. 「阻礙走火通道（即時處理）」預設已剔。
19. 唔係阻走火通道，就撳一下剔走。
20. 撳「生成 Word 信並記錄」。生成即係整出嚟。
21. 頁面會顯示「已記錄，編號 ……」。
22. 網上版會先彈一個框。撳同意，先會下載。
23. 封信會跟公司原本信嘅格式。
24. 相片喺附件一。附件即係跟喺信後面嘅嘢。

未打單位就撳掣？程式會提你「先輸入單位」。

「生成 Word 信並記錄」係灰色，撳唔到？即係呢個版本未載入 Word 範本。範本即係公司定好嘅信樣。未載入即係未放入程式。咁就只可以記錄，同埋列印文字版。

唔想即刻要 Word？可以咁做：

1. 撳「只記錄，稍後出信」。
2. 程式一樣會攞一個信件編號。
3. 一樣會記入雜物表同「信件紀錄」（文字版）。
4. 狀態會變「已出第一次信」。
5. 但唔會下載 Word。
6. 之後要 Word，喺表入面撳「Word」就下載到。

### 第二次信

呢節教你出第二次信。出咗第一次信，單位仲未清走，就用呢節。

做完會點：同一單位再出一次信。程式會自動變第二次通知。會用新編號。信入面會多一句，講返第一次信嘅日期。

用快速格出：

1. 喺「快速出雜物信」揀返同一「座」。
2. 打返同一個單位。
3. 淺藍色一行會寫「第二次通知」。
4. 仲會顯示第一次信嘅日期同編號。
5. 撳「生成 Word 信並記錄」。

要留意：嗰個單位嘅紀錄要仲未清理，先會變第二次。之前撳咗「已清理」或者「當垃圾處理」？再打同一個單位，就會當新一筆。會由第一次通知開始。

喺表入面出：

1. 喺表入面搵到嗰個單位。
2. 睇最右邊嗰欄第一個掣。
3. 出過第一次信嘅，個掣會變咗「第二次信」。
4. 撳「第二次信」。
5. 會跳去「信件草擬」頁。
6. 草稿已經填好。草稿即係未正式出嘅信。
7. 改好啲字。
8. 撳「儲存並編號」。
9. 程式會自動攞下一個編號。
10. 會記入雜物表同「信件紀錄」。
11. 再跳返雜物表。
12. 呢條路唔會自動下載 Word。
13. 要 Word，返到表入面撳「Word」。

未出過信嘅單位，個掣叫「出信」。做法一樣。

### 表入面其他掣

呢節教你表入面其他掣點用。清走咗雜物、改紀錄、睇相、搵紀錄，都用呢節。

每一行最右邊嗰欄仲有幾個掣。

「已清理」掣：

1. 雜物搬走咗，就撳「已清理」。
2. 會彈一個小窗。
3. 「日期」預設係今日。
4. 「結果」揀其中一個：
   - 「已清理」
   - 「當垃圾處理」
   - 「轉介支援」
5. 撳「儲存」。

「Word」掣：

1. 撳「Word」，就會再下載返之前嗰封信。
2. 編號同日期會同之前一樣。
3. 出過第二次信，就係第二次嗰封。
4. 出過信，先會有呢個掣。

「編輯」掣：

1. 想改紀錄，就撳「編輯」。
2. 會彈「編輯樓層雜物」窗。
3. 改完撳「儲存」。

睇相：

1. 睇「相」嗰欄。
2. 如果寫住「3 張」之類，撳一下。
3. 就可以睇相。
4. 入面有「加相片」，可以加相。
5. 撳「關閉」就收埋。

搵紀錄：

1. 表頂有個搜尋框。
2. 打單位或者物品，就篩到。篩到即係淨係顯示啱嘅嗰啲。
3. 「全部座」「全部狀態」都可以揀。
4. 想淨係睇未清理嘅，就剔「只顯示未清理」。

### 批量出信

呢節教你一次過為幾個單位出信。批量即係一次過做好多個。有好多單位要出信，就用呢個。

做完會點：一次過為幾個單位出信。程式自動編號。會記入「信件紀錄」。再一次過印。印嘅係文字版信，唔係 Word。

1. 表入面每行最左邊有個方格。
2. 要出信嘅單位，就剔嗰個方格。
3. 撳「批量出信（已選 3）」。
4. 括號入面個數字，係你剔咗幾多個。
5. 一個都未剔，個掣係灰色，撳唔到。
6. 會彈「確認」框。
7. 框入面會問你「為 3 個單位生成雜物信並編號」。
8. 撳「確定」。
9. 會去到「雜物信」頁。
10. 每封信一頁。
11. 撳「列印全部」。
12. 有相片，會跟喺信後面做附件一。
13. 印完撳「返回雜物表」。

之後要 Word，返到表入面逐個單位撳「Word」。

### 列印

呢節教你列印。列印即係用打印機印出嚟。想印張表上樓巡，或者印一封信，就用呢節。

印雜物表：

做完會點：印一張表。會按座同樓層分組。分組即係同一座、同一層嘅放埋一齊。淨係未清理嘅。最右邊有「巡查結果（手寫）」一欄。上樓可以手寫。

1. 撳頁頂「列印雜物表」。
2. 撳「列印」。
3. 印完撳「返回」。

印單一封信：

1. 喺表入面撳「出信」或者「第二次信」。
2. 喺「信件草擬」頁撳「列印」。
3. 撳「複製」，可以複製成封信嘅文字。複製即係抄低啲字。
4. 要留意：淨係撳「列印」，唔會記低。
5. 想攞編號、記入「信件紀錄」？就要撳「儲存並編號」。

### 雜物表 Excel

呢節教你出一個 Excel 雜物表。想要一個 Excel 版嘅雜物表，就用呢節。

做完會點：會出一個 Excel。用嘅係公司「樓層巡查剔格表」範本。總表每格列出單位號碼。②＝已出第二次信。✓＝已清理。每座一張分表。備註有物品、信件編號、日期。

1. 撳頁頂「下載雜物表 Excel」。
2. 會彈「下載樓層雜物表（Excel）」窗。
3. 「範圍」揀要邊啲紀錄。有四個可以揀：

   - 「全部未清理」
   - 「全部已出信（包括已清理）」
   - 「全部紀錄」
4. 預設係「已出信而未清理（預設）」。
5. 「由（出信／發現日期）」同「至」可以揀日期。
6. 唔揀日期，就係全部。
7. 「表上日期」預設係今日。
8. 「巡查員／製表」揀邊個。
9. 「標題」預設係「樓層雜物表」。
10. 撳「生成並下載」。
11. 頁面會顯示「已填入 N 項」。N 即係數目。
12. 網上版會先彈一個框。撳同意，先會下載。

### 另外兩個掣

呢節教你頁頂另外兩個掣。想出一個簡單表格檔案，就用第一個掣。淨係想記一筆、唔出信，就用第二個掣。

相片只存喺影相嗰部機。換咗另一部機，就睇唔到相。

## 樓層巡查剔格表

   - 未巡過嘅，座名都會變色。
4. 未開過任何一輪嘅話，下面會有一句字：
   「揀上面一座或者按「開始新一輪」」

### 開新一輪

呢節教你開一張新嘅剔格表。
巡樓之前，先喺度開一輪。
做完會點：會出現一張空嘅剔格表。

1. 撳你要巡嗰一座。

2. 會彈出「開始新一輪巡查」表格。

### 一格格撳

呢節教你點樣剔格。
巡緊樓，每到一層就會用到。

剔格表每一行係一層樓。
最高層喺最上面。
每層有「A翼」「B翼」「C翼」三格。
格仔有三個樣。
撳一下，就轉一次。

- 空格：未巡。
- 「✓」：正常，冇雜物。
- 「✗」：有雜物。

1. 巡到邊層，就搵嗰層嗰一行。
2. 嗰翼冇嘢，撳一下格仔。
   格仔會變「✓」。
3. 嗰翼有雜物，再撳多一下。
   格仔會變「✗」。
4. 撳錯咗，再撳多一下。
   格仔會變返空格。

表頂會寫住「已剔」幾多格。
即係幾多格正常、幾多格有雜物。

有啲格仔會見到一條橫線「—」。
即係嗰層冇住宅單位，唔使撳。
而家只有善景樓 2 樓係咁。
因為嗰層係安老院。

表下面有個「備註」欄。
可以打當日發現嘅嘢。
打完撳一下其他地方。
就會自動儲存。

### 撳到有雜物即刻記

呢節教你點樣記低雜物。
格仔變咗「✗」嗰陣，就會用到。

格仔一變「✗」，會即刻彈出一張表格。
表格叫「新增樓層雜物」。
下面呢幾格，已經自動填好：

- 「發現日期」
- 「樓」
- 「樓層」
- 「翼」
- 「跟進同事」

你只需要打兩樣嘢。

1. 「單位」：打單位號碼，例如 707。
2. 「物品」：打係咩雜物。
   例如：擺放紙箱三個、摺凳一張。
   「物品」後面仲寫住「寫落信度」。
   仲有一句例子，提你點寫。
3. 雜物阻住走火通道嘅話，就剔呢格：
   「阻礙走火通道／消防設備（即時處理）」
4. 撳「儲存」。
5. 儲存後，畫面會跳去「樓層雜物」頁。
   嗰條紀錄已經喺表入面。
6. 想繼續巡，有兩個方法。
   撳返左邊選單嘅「樓層巡查」。
   或者撳雜物表頁頂嘅「樓層巡查」掣。
   頭先嗰張剔格表會自動開返。

記低之後，返去剔格表睇。
嗰層最右邊有一欄「備註（當日發現）」。
嗰度會自動寫上單位代號同物品。
單位代號例如 SK707。

如果唔想記，撳「取消」。
格仔都係會留住「✗」。
之後可以喺「樓層雜物」頁出雜物信。

## 工程項目同承辦商

呢節教你記低維修工程，同做工程嘅公司。
屋苑有嘢要維修，就會用到。

「工程項目」係用嚟記維修工程。
例如換污水喉、整外牆。
一單工程由頭到尾，都可以跟住記低。
「承辦商」頁記每間公司做過嘅工單。
邊間公司有幾張工單未做完，一眼睇到。
邊間公司有幾張超時，都一眼睇到。

### 開一單新工程

呢節教你開一單新工程。
有新嘅維修要跟，就會用到。

做完會點：會即刻跳去嗰單工程自己嘅頁面。返去「工程項目」表，會見到多咗一行。

1. 撳左邊選單「工程項目」。
2. 撳右上「新工程項目」。
3. 喺「工程項目」打工程名。例如「善雅樓2701室換污水喉」。
4. 喺「樓」打邊一座。撳一下個格，座名會彈出嚟畀你揀。
5. 喺「單位／位置」打單位。例如 2701，或者「天台」。
6. 喺「工程類別」揀一個。可以揀「外牆」「喉管」「消防」。或者「電力」「園藝」「其他」。
7. 喺「狀態」揀而家去到邊一步。新工程通常係「事件起稿」。最底有個英文字「outstanding」，唔使理佢。
8. 喺「座主」揀負責嘅同事。
9. 喺「承辦商」打公司名。「承辦商」頁已經有嘅公司，會自動彈出嚟。你可以直接揀。
10. 其他格仔可以遲啲先填。例如「翼」「出標日期」「截標日期」。仲有「過會日期」「中標金額」。
11. 撳「儲存」。

要留意：「承辦商」要打足全名。要同「承辦商」頁嘅「公司名稱」一模一樣。咁樣兩邊先會連埋。連咗之後，工程頁嘅「承辦商」會變成連結。呢個連結係可以撳嘅。公司頁都會列出呢單工程。

仲有一個快方法。
做完會點：「樓」「單位／位置」「住戶身份」會自動填好。「登記電話」「關顧提示」都會自動填好。

1. 喺「單位查詢」頁查一個單位。
2. 撳「新工程」。

### 改工程狀態

呢節教你改一單工程去到邊一步。
工程有進展，就會用到。

狀態即係工程而家去到邊一步。
每單工程一共十二步。次序係：

「事件起稿」→「約上門」→「出信/通告」→「進行中」→「報價草稿」→「報價已發出」→「報價經理批核中」→「法團投票中」→「法團商議中」→「上會追認」→「約期/工程中」→「完工」

做完會點：工程會跳去新嗰步。「紀錄」會自動多一行。嗰行寫住「狀態：舊嗰步 → 新嗰步」。

1. 喺「工程項目」表撳嗰單工程。
2. 睇「流程」。有「現時」兩個字嗰一步，就係而家嘅狀態。
3. 搵你想去嘅一步。
4. 撳嗰行右邊嘅「設為此步」。

要留意：喺「完工」嗰行撳「設為此步」。「完工日期」本身未填嘅話，會自動填今日。反過嚟，撳「編輯」填咗「完工日期」。狀態都會自動變「完工」。
工程頁右上仲有三個掣。就係「編輯」「出信」「刪除」。「出信」會跳去「信件草擬」頁。

### 記一筆

呢節教你喺工程度寫低發生咗咩事。
例如打完電話畀住戶，就可以記低。

做完會點：「紀錄」會多一行。有日期時間，有你打嘅字。最新嘅喺最上面。

1. 打開嗰單工程。
2. 撳「紀錄」右邊嘅「記一筆」。
3. 喺「內容」打發生咗咩事。例如「已致電住戶約期」。
4. 撳「儲存」。

### 篩選工程表

呢節教你喺工程表淨係睇某啲工程。
工程太多，想搵某一單，就會用到。

篩選即係淨係顯示你想睇嗰啲。

做完會點：表淨係顯示你揀嘅工程。

1. 撳左邊選單「工程項目」。
2. 頂部有個搜尋框。框入面寫住「搜尋單位代號、工程、承辦商…」。喺度打單位代號或者工程名。打承辦商名都得。
3. 撳「全部狀態」，揀一個狀態。例如淨係睇「法團投票中」。狀態後面有個括號數字。即係嗰步有幾多單工程。
4. 撳「全部座」，揀一座。
5. 撳「全部座主」，揀一個同事。
6. 「只顯示未完工」平時係剔住嘅。想睇埋完咗工嘅，撳一下除咗個剔。

要留意：有時「截標日期」過咗，仲未填「承辦商」。咁個日期喺表入面會變紅色。「今日」頁嘅「工程項目」一欄都會提你。截標前兩日就會開始提。同一欄仲會提你另外兩樣嘢。一、邊單「約期/工程中」超過 30 日未完工。二、有幾多單等緊「上會追認」。
「匯出 CSV」會下載成個表。唔理你篩咗咩，全部工程都會喺入面。

### 新增承辦商

呢節教你加一間新公司落「承辦商」頁。
有新公司幫屋苑做工程，就會用到。

做完會點：會即刻跳去嗰間公司自己嘅頁面。返去「承辦商」頁都會見到佢。

1. 撳左邊選單「承辦商」。
2. 撳右上「新承辦商」。
3. 喺「公司名稱」打公司名。
4. 喺「聯絡人」打聯絡人嘅名。
5. 喺「電話」打電話號碼。
6. 喺「合約」打合約名或者編號。
7. 喺「SLA 到場／完成日數」打日數。SLA 即係合約訂明幾多日內要做完。預設係 3。
8. 「備註（條款、罰則）」可以打合約重點。
9. 撳「儲存」。

### 開工單

呢節教你同一間公司開一張工單。
要叫公司做嘢，就會用到。

做完會點：工單會出現喺「工單」表。「狀態」會係「進行中」。「限期」會按 SLA 日數自動計好。

1. 喺「承辦商」頁撳嗰間公司。
2. 撳「工單」右邊嘅「新工單」。
3. 喺「內容」打要做咩。例如「善群樓 7 樓走廊燈壞」。
4. 「發出日期」預設係今日。有需要先改。改咗「發出日期」，「限期」會自動再計過。
5. 「限期」已經自動填好。有需要先改。
6. 撳「儲存」。

### 工單完成咗

呢節教你記低一張工單做完咗。
公司做完嘢，就會用到。

做完會點：嗰行嘅「完成」會填今日日期。「狀態」會變「完成」。遲咗先完成，會顯示「遲完成」。

1. 喺「承辦商」頁撳嗰間公司。
2. 喺「工單」表搵嗰張工單。
3. 撳右邊「完成」。

要留意：有時工單過咗「限期」，仲未完成。咁嗰行「狀態」會顯示紅色嘅「超時」。「今日」頁嘅「承辦商工單超時」都會提你。工單右邊仲有個「刪」掣。撳咗會刪走嗰張工單，要小心。
撳入嗰間公司嘅頁面。會見到「事實摘要（可以直接放入信）」。入面會自動寫晒邊張工單超時幾多日。出信嘅時候可以照抄。
想正式跟進，可以開個案：

1. 撳右上「開承辦商個案」。
2. 會彈出「新個案」表格。「標題」已經填好「公司名：工單超時」。對方同類型都已經填好。
3. 撳「儲存」。就開咗個案。



## 信件同其他工具

呢節教你用「工具」入面嘅五樣嘢。即係出信、查條例、準備傾嘢、判斷個案。諗緊一宗個案點處理嗰陣，就會用到。

左邊選單有一欄叫「工具」。入面有五樣嘢：

- 「法規導航」
- 「信件草擬」
- 「信件紀錄」
- 「對話準備」
- 「形勢判斷」

開住一宗個案嗰陣，個案頁頂有捷徑。

- 撳「出信」，去草擬信。
- 撳「準備對話」，去對話準備。
- 撳「判斷」，去呢宗個案嘅形勢判斷。


### 信件草擬

呢節教你出一封信。想寫信畀住戶或者其他人，就用呢頁。程式會幫你填好大部分字。

[[img:letters]]

1. 左邊選單撳「信件草擬」。或者喺個案頁撳「出信」。
2. 想連住一宗個案，撳右上角個下拉選單。佢本身寫住「— 唔連結個案 —」。
3. 揀你嗰宗個案。只會列出未結案嘅個案。未結案即係仲未搞掂嘅個案。
   做完會點：草稿會自動填入個案資料。程式仲會自動幫你揀一種信。
   要留意：一定要先揀個案。跟住先揀信種類。最後先改字。如果你先改字，再揀個案，改咗嘅字會冇晒。
4. 睇頁頂嗰排分頁。分頁即係一排可以轉嘅標籤。揀你要嘅信種類：
   - 「覆投訴信」
   - 「紀錄信」
   - 「拒絕信」
   - 「警告信」
   - 「安排檢查通知」
   - 「通告／提示」
   - 「樓層雜物信」
   分頁下面有三格：
   - 「呢封信要攞咩」
   - 「次序（最常見嘅錯係由第三段開始寫）」
   - 「先諗清楚」
   出信之前睇一睇呢三格。
5. 喺「草稿」嗰格改字。直接喺大格入面改就得。
6. 睇草稿下面嘅提示。見到問題就改：
   - 見到「書面唔應該出現嘅字眼」，就要改。例如「盡快」「屢勸不聽」都唔可以用。提示會話你知點解唔好。
   - 見到「仲有 N 個［方括號］未填」，就填晒佢。N 即係一個數字。［方括號］即係呢種括號。
   - 見到「內文冇具體日期」，就寫明日期。
   - 見到「信上冇你嘅牌照號碼」，就補返。
   改到見「掃描冇發現問題」就得。掃描即係程式幫你檢查成封信。
7. 睇「信件編號」。佢已經自動填好，改唔到。
8. 「內容（紀錄用）」同「收件人」可以改。想改就喺度改。
9. 撳「儲存並編號」。
   做完會點：畫面會彈「已儲存，編號 FUSN/26/L…」。封信會自動記入「信件紀錄」。
   有連住個案嘅話：個案嘅「接觸紀錄」會多一行「出咗……信」。畫面會自動跳返去個案頁。
   冇連住個案嘅話：會跳去「信件紀錄」。
10. 想印出嚟，撳「列印」。
11. 想貼去電郵，撳「複製」。之後可以貼去第二度。
12. 改到亂晒，想由頭嚟過，撳「用範本重新生成」。
13. 想睇返出過嘅信，撳頁頂嘅「信件紀錄」。

要留意：

- 信尾會自動加你嘅姓名同牌照號碼。所以要先去「設定／備份」。填「姓名」同「物業管理人牌照號碼」。
- 「樓層雜物信」唔同。佢係用「物業經理（簽署人）」同「經理牌照號碼」簽嘅。
- 連住個案，再揀「警告信」嗰陣，程式會查次序。次序即係先做咩、後做咩。見到下面任何一樣，就會有黃色提示：
  - 「紀錄上未有口頭接觸」（口頭即係用口講）
  - 「未出過紀錄信」
  - 「階梯仍然喺第 N 級」（即係未升到「正式程序」）
  黃色提示寫住「出警告信之前：我要改善，定係要紀錄？」。
  三樣都齊，就會見到綠色字。寫住「口頭 → 紀錄信 → 死線 → 警告信：次序上企得穩。」。
  即係先口頭講。再出紀錄信。再定死線。最後先出警告信。死線即係最後限期。
- 連住個案嘅信可以再改。去「信件紀錄」撳「開」。改完撳「儲存修改」。

### 信件紀錄

呢節教你睇返出過嘅信。想搵返舊信，或者刪紀錄，就用呢頁。所有喺程式出過嘅信，都喺呢頁。

1. 左邊選單撳「信件紀錄」。
2. 睇個表格。表格有六欄：
   - 「編號」
   - 「日期」
   - 「內容」
   - 「發件人」
   - 「收件人」
   - 「類別」
   編號最大嘅信排最上。編號最大即係最新嗰封。
3. 睇頁頂嘅「下一個編號」。即係下一封信嘅編號。
4. 想改前綴或者流水號，去「設定／備份」頁。改「信件編號前綴」同「下一個信件編號」。流水號即係順序加上去嘅數字。
5. 想睇返封信，撳嗰行嘅「開」。
   做完會點：有連住個案嘅信，會去返「信件草擬」畀你改。冇連住個案嘅信，只會彈一個框畀你睇。睇完撳「關閉」。
   要留意：由 Excel 匯入、冇內文嘅信，冇「開」掣。
6. 想出新信，撳「草擬新信」。
7. 想攞去 Excel 用，撳「匯出 CSV」。
   網上版會先彈一個框。撳同意，先會下載。
   有時會彈出「呢個環境唔可以直接下載檔案」。咁就撳「複製」，再貼去記事本儲存。記事本即係電腦入面打字嘅簡單程式。
8. 想刪走一筆紀錄，撳「刪」。
   會彈「刪除呢筆信件紀錄？編號唔會回收。」。
   撳「確定」先會刪。撳「取消」就唔刪。
   要留意：編號唔會回收。即係刪咗之後，嗰個編號唔會再用。

### 法規導航

呢節教你查個案歸邊條條例、邊個部門。未決定點做之前，先用呢頁查。條例即係法律。

1. 左邊選單撳「法規導航」。
2. 睇第一格。個格叫「第一個問題：呢個處所屬邊種？」。處所即係嗰個地方，例如個單位。
3. 揀「處所類型」。有四種：
   - 「房委會租住單位」
   - 「租者置其屋計劃單位」
   - 「私人樓宇（有公契）」
   - 「邨內商業／機構租戶」
   公契即係大廈嘅規矩文件。
   唔肯定就唔好估。留住「— 未確定（先問清楚，唔好估）—」。先問清楚住戶。
   未揀嘅話，頁面只會寫住「揀咗處所類型先有答案」。
4. 揀「個案類型」。佢本身寫住「滲水」。例如：
   - 「滲水」
   - 「噪音」
   - 「走廊／大堂雜物」
   - 「承辦商／採購」
   採購即係買嘢或者請人做嘢。
   做完會點：頁面即刻顯示幾格。
   - 「歸邊條例／邊個部門」：邊條法例、邊個政府部門管。入面仲有「你有咩權限、冇咩權限」。即係你做得啲咩。有時仲有「相關轉介」。轉介即係交畀其他部門跟進。
   - 「程序形狀同時限」：一步步點行、幾多日。
   - 黃色「要核實」：行動前要查清楚嘅嘢。核實即係查清楚係咪真。
5. 行動前，去「查證來源」撳連結核實。因為條例同時限會改。
6. 睇頁底「個案 → 歸邊度（總表）」。一眼睇晒全部個案類型歸邊度。旁邊有「你自己嘅牌照責任（第626章）」。第626章即係一條法例嘅編號。

要留意：個案頁有一格「歸邊度」。嗰格撳「詳細」，都會去到呢頁。不過去到之後，要自己再揀「處所類型」同「個案類型」。

### 對話準備

呢節教你準備同人傾嘢。上門或者打電話之前，先用呢頁。

1. 左邊選單撳「對話準備」。或者喺個案頁撳「準備對話」。
2. 睇第一個分頁「場景 playbook」。playbook 即係對話劇本。場景即係你會遇到嘅情況。
3. 揀「場景」。有七種：
   - 「上層住戶唔肯開門畀你查滲水」
   - 「投訴人嫌慢／要即刻有答案」
   - 「承辦商拖延或者推卸責任」
   - 「走廊、大堂堆放雜物」
   - 「收費／按金爭拗」
   - 「同事或前線員工衝突」
   - 「三方糾紛（樓上、樓下，夾埋你）」
   做完會點：頁面會顯示幾格。
   - 「佢真正想要／驚嘅係咩」
   - 「次序（可以照讀）」：開場講咩、跟住問咩。
   - 「對方可能點回應 → 你點接」
   - 「幾時收手」：收手即係停，唔再傾落去。
   - 「書面跟進」：傾完要出咩信。
   - 「收尾一定要齊四樣」：邊個、做咩、幾時、點覆。
4. 想連住個案，撳右上角個下拉選單。佢本身寫住「— 唔連結個案 —」。
5. 揀你嗰宗個案。只會列出未結案嘅個案。
   做完會點：程式會按個案類型自動揀場景。分頁上面會多一格「三條線」。入面有：
   - 「目標」
   - 「底線」
   - 「我嘅 BATNA」
   - 「對方利益」
   BATNA 即係傾唔掂時嘅後備方案。底線即係最低可以接受嘅條件。
6. 撳「三條線」嗰格嘅「編輯」。會彈出「目標 / 底線 / BATNA」。
7. 填五樣嘢：
   - 「目標（具體到邊個、做咩、幾時）」
   - 「底線（低過呢條就唔好傾落去，轉程序）」
   - 「我傾唔掂會點（BATNA）」
   - 「對方傾唔掂會點」
   - 「對方真正嘅利益（唔係佢講嗰樣）」
8. 填完撳「儲存」。
9. 撳「對白庫」分頁。入面係一句句可以照講嘅廣東話。
10. 出門前，撳「出門前檢查」分頁。會見到「出門前」一格。
11. 逐項剔格。呢啲剔格淨係畀你自己當場睇。唔會儲存。轉咗分頁就會清返。

### 形勢判斷

呢節教你判斷一宗個案值唔值得推落去。唔知應唔應該繼續推一宗個案，就用呢頁。

1. 左邊選單撳「形勢判斷」。
   做完會點：見到「形勢判斷 · 個案盤點」。盤點即係數一數有幾多宗。
   未結案嘅個案分四組：
   - 「未分類」
   - 「要推」
   - 「等得」
   - 「應該結」
   每組個名後面有括號，寫住幾多宗。
   每宗會寫住「N 日冇進展」同「階梯 N」。
   有啲個案可能超過六十日冇進展。咁頁頂會有黃色提示。提示寫住「N 宗連續兩個月冇實質進展」。
2. 每宗個案揀一個：「等得」「要推」或者「應該結」。
   「等得」即係等緊第三方。
   「要推」即係要定死下一步。
   「應該結」即係唔推，寫低點解。
3. 會彈出一個框。打「一句理由（寫入紀錄）」。
4. 撳「儲存」。做完會點：理由會寫入個案嘅「接觸紀錄」。
5. 想深入判斷一宗個案，撳個案名。會入到個案頁。
6. 喺個案頁撳「判斷」。
7. 「七計對比」有七條問題。每條撳一個：「我方」「平手」「對方」。
   做完會點：「七計對比」標題右邊會有字。寫住「你贏 N · 輸 N」。
   如果輸三條或以上，會有紅色提示。提示寫住「唔好行強硬路線」。強硬即係用硬方法迫對方。
8. 「五事」有五項：「道」「天」「地」「將」「法」。每項打一句。
9. 弱嘅嗰項撳「標紅」。標紅即係記低呢項係弱嘅。撳咗會變「已標紅」。再撳一次就取消。
10. 「兩邊嘅底」有兩樣：
    - 「我傾唔掂會點」
    - 「佢傾唔掂會點」
    撳「編輯」。會彈出「目標 / 底線 / BATNA」。
11. 填你同對方傾唔掂會點。
12. 「拖係最大嘅敵人」會顯示幾多日冇實質進展。撳一個：
    - 「會——等得，定檢查點」
    - 「唔會——要推」
    - 「唔會——應該結」
    檢查點即係定個日子再睇返。
13. 打「一句理由（寫入紀錄）」。
14. 撳「儲存」。
15. 「留返個缺口」打一句。問題係「我而家開出嘅條件，對方接受咗之後仲有冇面？」。即係諗下對方接受咗，會唔會冇面。
16. 睇「建議層級」。佢顯示你而家喺第幾級。有四級：
    - 「非正式溝通」
    - 「借助第三方」
    - 「正式程序」
    - 「法律／租約行動」
    唔好跳級。
17. 想升級，返個案頁撳「升一級 →」。升級即係去上一級。
18. 會彈個框。打「點解升級（寫入紀錄）」。
19. 撳「確定升級」。
20. 睇完撳右上角「返回個案」。

要留意：安全個案唔會喺呢頁嘅盤點入面。走火通道、消防、結構呢啲，要即刻處理。冇得計值唔值得。有時你會由個案頁撳「判斷」入嚟。如果嗰宗係安全個案，頁頂會有紅色「安全個案冇得計數」。

## 備份同常見問題

呢一節教你點樣保住啲資料。
仲有幾個常見問題嘅答案。

### 點解要備份

呢節講點解要備份。
開始用之前，先睇一次。

資料全部存喺你部機嘅瀏覽器入面。
例如 Chrome。
資料唔會上載去任何地方。
上載即係傳上網。
不過，有幾個情況資料會冇晒：

- 換咗另一部機
- 換咗另一個瀏覽器
- 清咗瀏覽紀錄

瀏覽紀錄即係上網嘅紀錄。
所以每星期要備份一次。
最好定一日做。
例如星期五放工前。
「設定／備份」頁有一格叫「備份」。
嗰格都寫住：每星期匯出一次。


### 每星期備份一次

呢節教你點樣做備份。
每星期做一次。
做完會點：你部機會多一個備份檔。

網上版同單一檔案版都係咁做。

1. 撳左邊選單嘅「設定／備份」。
2. 搵「備份」嗰一格。
3. 撳「匯出 JSON」。
4. 網上版會先彈一個框。個框問你儲唔儲存。撳同意。
5. 單一檔案版唔會彈框。檔案會直接下載。
6. 頁底會閃「已儲存」。後面跟住檔案名。大約兩秒會自動消失。
7. 檔案名係 pmo-backup-日期.json。例如 pmo-backup-2026-10-12.json。
8. 將個檔案放入公司指定嘅位置。

JSON 係備份檔嘅格式。
你唔使理。
當佢係備份檔就得。

備份檔有住戶嘅個人資料。
唔好放個人雲端。
唔好用通訊程式傳出去。
通訊程式即係傾偈用嘅程式，例如 WhatsApp。

### 還原備份

呢節教你用備份檔攞返資料。
還原即係將資料變返以前嘅樣。
幾時用：換咗新機，或者資料唔見咗。
做完會點：資料會變返備份嗰日嘅樣。

呢次要用「匯入 JSON」。

1. 撳「設定／備份」。
2. 撳「匯入 JSON」。
3. 揀返你存低嘅備份檔。
4. 會彈一個「確認」框。上面寫住：「匯入會覆蓋現有資料（幾多宗個案）。繼續？」
5. 撳「確定」。
6. 頁底會閃「已匯入」。

要留意：還原會覆蓋而家嘅資料。
即係而家嘅資料會變成備份嗰份。
如果而家有新資料，先撳「匯出 JSON」。
咁樣先有保險。
如果揀錯檔，頁底會閃「匯入失敗：格式唔啱」。
唔使驚。
再揀過個備份檔就得。

### 相片去咗邊

呢節講相片存喺邊度。
換機之前，一定要睇。

相片同其他資料分開存。
相片只存喺影相嗰部機。
備份檔唔包相片。
換機之後，相片唔會跟過去。
還原備份都唔會有相。
重要嘅相，要另外存一份。
出咗嘅 Word 信，有相片做附件一。
留住個 Word 檔，相就唔會唔見。

### 私隱

呢節講私隱。
私隱即係唔可以畀人隨便睇嘅資料。
睇完你會知邊啲嘢唔可以做。

資料唔會上載，淨係喺你部機。
備份檔有住戶個人資料（第486章）。
第486章係保障個人資料嘅法例。
備份檔要存喺公司指定位置。
唔好放個人雲端。
唔好傳畀唔相關嘅人。
Excel 密碼喺你部機入面解。
密碼唔會傳去任何地方。

### 示範資料

呢節講示範資料。
想清走，或者想再睇示範，就用呢節。

網上版第一次開，會自動載入示範資料。
載入即係自動放咗入嚟。
「今日」頁頂有一句藍色提示。
提示寫住：「而家顯示嘅係示範資料」。
提示入面叫你去「設定」。
「設定」即係左邊選單嘅「設定／備份」。
示範資料全部係假嘅例子。
唔係真人真事。
真正使用之前，要清走佢。
點清走，睇「第一次用」第一步。
清走之後，返去「今日」頁。
藍色提示會唔見咗。
會改為見到「開始使用」提示。呢個係正常嘅。

想再睇示範？
去「危險區」撳「載入示範資料」。
「開始使用」提示入面都有「載入示範資料」。
嗰個係一個連結，撳佢都得。
要留意：載入示範資料，唔會先清走而家嘅資料。
佢係加落你而家嘅資料上面。
所以有真資料就唔好撳。
否則真假資料會溝埋。
真係想睇，先撳「匯出 JSON」備份。
睇完用「匯入 JSON」還原返。

### 常見問題

呢節答幾個常見問題。
遇到問題，嚟呢度搵答案。

**下載唔到**

撳咗掣，但係冇檔案落嚟，就睇呢度。

1. 網上版下載前會先彈一個框。撳同意先會下載。
2. 單一檔案版唔會彈框。
3. 如果撳咗取消，就唔會儲存。
4. 出 Word 信嗰陣，頁底會閃「已取消儲存」。再撳多次個掣就得。
5. 出備份嗰陣，可能會彈一個框。個框會話「呢個環境唔可以直接下載檔案」。
6. 咁就撳框入面嘅「複製」。頁底會閃「已複製」。
7. 然後開一個文字檔。文字檔即係淨係得字嘅檔案。
8. 貼上去。
9. 存起佢，當係備份。
10. 撳「關閉」收起個框。
11. 出雜物 Word 信嗰陣，可能會彈一個框。個框會話「呢個網頁環境唔可以下載檔案」。
12. 咁就撳「列印文字版」。可以印一張文字版頂住。文字版都有相片附件。
13. 撳「關閉」收起個框。
14. 想出返真正嘅 Word 檔，就用單一檔案版。


**密碼唔啱**

打咗密碼但係唔啱，就睇呢度。

1. 會見到「密碼唔啱，再試」。個框會再彈出。
2. 再打一次密碼。
3. 撳「解密」。
4. 唔想繼續，撳「取消」。
5. 仲係唔得，問返畀你檔案嗰位同事。

詳細步驟，睇「第一次用」入面「匯入住戶登記表（有密碼）」。

**資料唔見咗**

開個程式，資料全部唔見咗，就睇呢度。

1. 諗下係咪換咗機。
2. 諗下係咪換咗瀏覽器。
3. 諗下係咪清咗瀏覽紀錄。
4. 試用返原本嗰部機同原本嗰個瀏覽器開。
5. 仲係冇，就用「匯入 JSON」。點做，睇「還原備份」。
6. 還原返最近嘅備份。
7. 冇備份就還原唔到。所以每星期要備份。

**相片唔見咗**

相片唔見咗，就睇呢度。

1. 相片只存喺影相嗰部機。
2. 用返嗰部機開，就會見到。
3. 去「樓層雜物」頁。
4. 撳「相」嗰欄嘅「幾多張」掣。
5. 可能見到「呢部機冇儲存呢個單位嘅相片」。咁即係相片喺另一部機。
6. 備份檔唔包相片。詳細睇「相片去咗邊」。

## 用詞對照

- 撳＝用手指或者滑鼠撳一下（全書只用「撳」，唔用「按」「點」）
- 網上版＝用連結開嘅版本，要上網、要登入
- 單一檔案版＝pmo-workbench.html 呢個檔，冇網絡都開到
- 瀏覽器＝上網用嘅程式，例如 Safari、Chrome、Edge
- 登入＝用你個帳戶入去
- 檔主＝呢個程式嘅主人
- 示範資料＝假嘅例子，畀你試玩
- 下載＝將檔案攞落嚟部機
- 下載資料夾＝電腦放落嚟檔案嘅地方
- 主畫面＝手機一開就見到嗰頁
- 「☰」＝左上角三條橫線嘅掣，撳一下彈出選單
- 選單＝畫面左邊嗰排可以揀頁嘅清單
- 下拉選單＝撳落去會彈個名單畀你揀嘅格
- 備份＝留多一份資料
- 備份檔＝撳「匯出 JSON」落嚟嘅檔案，叫 pmo-backup-日期.json
- 匯出＝將資料存做一個檔案
- 匯入＝將檔案入面嘅資料攞入嚟（Excel 或者備份檔都係咁叫）
- 還原＝用備份檔將資料變返以前嘅樣
- 覆蓋＝用新資料換走舊資料
- 預設＝預先準備好、一開始已經填好嘅嘢
- 範本＝公司定好嘅信樣或者表樣
- 草稿＝未正式出嘅信
- 解密＝用密碼開鎖
- 承辦商＝做工程嘅公司
- 工單＝派畀承辦商做嘅工作
- 前綴＝編號最前面嗰幾個字
- 代號＝座名嘅英文簡寫，例如 SK
- 個案＝一宗投訴或者要跟進嘅事
- 結案＝呢宗個案完結咗
- 業戶＝買咗層樓嘅人
- 租戶＝租緊嘅人
- 剔格表＝每層每翼一格嘅巡樓表
- 截標＝收標書嘅最後一日
- 追認＝事後先攞上會批
- 狀態＝工程或者個案而家去到邊一步
- 私隱＝唔可以畀人隨便睇嘅資料
- 第486章＝保障個人資料嘅法例
- 頁底會閃＝畫面最底短暫出現一句字
