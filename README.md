# 物管日常工作台

畀香港物業主任／屋邨管理人員日常用嘅個案跟進工具。純前端，唔使安裝、唔使伺服器、唔使上網：打開 `index.html` 就用得。資料只儲存喺你自己部機嘅瀏覽器（localStorage），唔會傳去任何地方。

## 點用

1. 下載或者 clone 呢個 repo
2. 用瀏覽器打開 `index.html`（Chrome、Edge、Safari、Firefox 都得）
3. 去「設定」填姓名、牌照號碼、屋邨名稱、電話——信件會自動用
4. 想睇下個系統點運作，可以喺「今日」或「設定」載入示範資料
5. **每星期匯出一次 JSON 備份**。清除瀏覽紀錄、換機、換瀏覽器都會冇晒資料

想放喺公司內聯網畀成個辦事處用，將成個資料夾放上任何靜態網頁伺服器就得。每個人嘅資料仍然係各自儲喺自己瀏覽器。

## 有咩功能

| 畫面 | 做咩 |
|---|---|
| **今日** | 應承咗覆投訴人嘅、逾期跟進嘅、今日到期嘅、承辦商工單超時嘅、連續兩個月冇進展嘅——一頁睇晒。安全個案（走火通道、消防、結構）永遠置頂 |
| **個案** | 每宗個案記：處所類型（房委會租住／租置／私人有公契／商業租戶）、投訴人、對方、下一步同期限、應承幾時覆命、上門次數、接觸紀錄時間線。滲水個案有專區：自動分辨 2026 年 7 月 16 日前後嘅新舊程序，計 6 個工作天、14 個工作天、28 個曆日嘅時限 |
| **巡查** | 記錄每日巡查，發現問題一鍵開個案；涉及安全嘅自動標記 |
| **承辦商** | 合約 SLA、工單限期、超時次數；自動生成一段冇形容詞嘅「事實摘要」，可以直接放入紀錄信或警告信 |
| **法規導航** | 揀處所類型 + 個案類型 → 歸邊條例、邊個部門、你有咩權限、程序形狀同時限、要核實啲咩、去邊度查 |
| **信件草擬** | 覆投訴信、紀錄信、拒絕信、警告信、安排檢查通知、通告——按個案資料填好範本，出信前掃描「書面唔應該出現嘅字眼」（屢勸不聽、盡快、顯然、恕難接納……），檢查有冇具體日期、有冇牌照號碼。出警告信前檢查有冇先行過口頭 → 紀錄信 → 死線 |
| **對話準備** | 六個常見場景嘅 playbook（拒絕開門、投訴人嫌慢、承辦商拖延、走廊雜物、收費爭拗、同事衝突、三方糾紛）：對方真正驚咩、開場、次序、對方點回應你點接、幾時收手、書面跟進。另有廣東話對白庫同出門前檢查表 |
| **形勢判斷** | 每宗個案：七計對比（輸三條或以上就唔好行強硬路線）、五事、兩邊嘅 BATNA、手段階梯（非正式溝通 → 借助第三方 → 正式程序 → 法律行動，冇試過上一層唔好跳）。每月盤點：將冇進展嘅個案分「等得／要推／應該結」，理由寫入紀錄。升級前有「嬲住唔好開戰」三條自我檢查 |

## 內置嘅規則（由用戶自己嘅工作方法整理）

- **第一個問題永遠係處所類型**。私人樓宇嘅聯辦處程序唔可以套落房委會租住單位度
- **安全同法定事項冇酌情**——走火通道、消防設備、結構危險即時處理，唔入「值唔值得」計算
- **弱勢住戶唔適用成本計算**——判斷係轉介，唔係「呢單唔值得搞」
- **記事實，唔記情緒**——「對方表示不滿並要求即時處理」，唔係「對方情緒激動」
- **應承咗嘅日期一定要做到**——就算冇進展都要覆
- **口頭傾完即日出紀錄信**；出警告信之前要行過口頭 → 紀錄信 → 死線
- **連續兩個月冇實質進展就要決定**升級定結案；唔升級又唔結案係純損耗
- **結案唔等於唔記錄**——要寫低點解唔推、幾時再睇

## 重要提示

- **呢個系統係導航，唔係權威，亦唔係法律意見。** 條例、程序、時限會改（滲水程序 2026 年 7 月就改過）。任何具體數字用之前，向「法規導航」列出嘅原始來源核實。涉及檢控、租約終止、索償、紀律程序，問法律部門或上級
- **房委會內部程序唔喺呢度**——以房署內部通函、租約條款同屋邨管理指引為準
- **個人資料**：個案入面有住戶姓名、電話、單位。匯出嘅備份檔存喺公司指定位置，唔好放個人雲端或者傳出去（第486章）
- 工作天計算只跳過星期六日，未扣公眾假期

## 檔案結構

```
index.html      頁面骨架
css/style.css   樣式（支援深色模式、手機、列印）
js/data.js      參考資料：條例、部門、程序、對白、信件範本、playbook
js/app.js       主程式：狀態、路由、九個畫面
tests/smoke.mjs 瀏覽器冒煙測試（Playwright）
```

想改條例資料或者信件範本，全部喺 `js/data.js`，唔使掂主程式。

## 測試

```
npm install        # 裝 playwright（只係測試用）
npm test           # 開 Chromium 行勻每個畫面
```

如果部機已經有全域安裝嘅 playwright，唔使 `npm install`，直接 `node tests/smoke.mjs`（可以用 `PLAYWRIGHT_GLOBAL` 指定路徑）。
